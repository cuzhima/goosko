📱 Подключение в Termius

  1. Termius → Keychain → Keys → Add → вставь приватный ключ, имя: GOOSKO temp #{{ cert_id }}.
  2. Termius → Keychain → Certificates (или настройки ключа) → Add → вставь сертификат.
  3. Создай Host: адрес {{ host_hint }}, порт 22, пользователь {{ principal }}.
  4. В настройках Host → Authentication выбери ключ GOOSKO temp #{{ cert_id }} (сертификат подцепится автоматически).
  5. Connect. Готово до {{ expires }} UTC.

💻 Подключение из терминала

Положи оба файла в одну папку и выполни:

chmod 600 goosko_key
ssh -i goosko_key -o CertificateFile=goosko_key-cert.pub {{ principal }}@{{ host_hint }}

OpenSSH также подхватит сертификат автоматически, если файл лежит рядом с ключом и называется goosko_key-cert.pub.
